# 剧本语法

剧本是 `content/` 下的 `.story` 纯文本文件，按文件名顺序读入。改完运行 `npm run check-story` 检查跳转和死路。

| 写法 | 含义 |
|---|---|
| `# 节点名` | 开始一个节点（英文、数字、下划线） |
| `@chapter 第一归 · 入门当年 · 秋` | 设置顶部章节名 |
| `@scene 温家旧门 \| 槐荫村东` | 切换场景（主名 \| 副名） |
| 普通一行 | 旁白 |
| `温小满：你是仙人？` | 对白（全角冒号，名字最多 8 个字） |
| `〔获得术法……〕` | 系统提示 |
| `+ 选项文字` | 选项；连续几行组成一组 |
| `  缩进两格的行` | 只在选了上一个选项后播放 |
| `+ 选项文字 -> 节点` | 选完跳到某个节点 |
| `-> 节点` | 跳转；`-> back` 回到上一个调查点 |
| `@investigate` | 调查点列表，下面接 `> 名称 -> 节点` |
| `>> 名称 -> 节点` | 离开调查的出口，全部查看过之后才出现 |
| `~ set 键 = 值` | 记录事实（true / false / 数字 / 文字） |
| `~ clue 键 文字` | 记入旧事录的线索 |
| `~ spell 术法名` | 习得术法 |
| `~ goal 文字` | 设置当前目标 |
| `@end 文字` | 结局卡片，`\n` 换行 |
| `@scene 名 \| 副标题 \| 时辰/状态 \| 插画文件名` | 时辰：dawn day dusk night snow spring；插画文件名对应 assets/scenes/ |
| `@cast 温小满=温小满_13岁` | 设置说话人当前用哪套立绘（年龄、时期） |
| `温小满[笑]：……` | 带表情的对白，对应立绘 `温小满_13岁_笑` |
| `@cg 文件名 \| 说明` | 全屏插画（assets/cg/），没图时显示占位卡 |
| `@card 文字` | 全屏字卡（时间跳转） |
| `@music 名` / `@music stop` | 背景音乐：主题 山门 村庄 夜与异常 挑战 结局 回忆 |
| `@sfx 名` | 音效：knock seal brush bell sense crack …… |
| `@battle b1` | 进入挑战（content/battles.json），结果写入 `b1.win` `b1.objectHp` 等 |
| `@draw v1` | 补符小游戏（v1 / fix / seal） |
| `@checkpoint 标签` | 关键选择前自动存档，可在「章节回溯」里读取 |
| `@pause 毫秒` | 停顿 |
| `+ 选项 [lock?条件 原因]` | 选项始终显示，条件不满足时锁住并显示原因 |
| `[?条件] 任意一行` / `一行 [?条件]` | 满足条件才执行 |
| `// 注释` | 不会显示 |

条件写法：`键`（为真）、`!键`（为假）、`键=值`、`键!=值`、`键>数字`、`键<数字`，用 `&` 连接多个。
自动记录：进入节点会设 `seen.节点名`，获得线索会设 `clue.键`。
`{name}` 会替换成主角名字。
