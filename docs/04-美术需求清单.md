# 《归山》美术需求清单 v1

> 给绘图模型用的清单。每张图都有**文件名**、**尺寸**和**可以直接复制的提示词**。
> 建议先做「第一批」，出 1–2 张就发给我看效果，确认画风后再批量出。
> 没出的图，游戏会自动使用代码生成的水墨占位图，所以可以出一张替换一张。

---

## 一、怎么把图交给我

两种方式，任选一种：

1. **直接上传到仓库（推荐，手机也能操作）**
   打开 https://github.com/chxx520/Moklihuaxiuxian ，进入 `assets` 文件夹 → 再进入对应的子文件夹 → 右上角「Add file」→「Upload files」→ 选图 → 页面底部点「Commit changes」。
   **文件名请按清单里的写**，例如 `温小满_8岁_笑.png`。名字对了，游戏会自动识别。
2. **在对话里发给我**：附上文件名或编号，我来放进去。

格式：PNG 或 JPG 都可以，单张最好不超过 5 MB。

## 二、统一画风（每条提示词前面都要加这一段）

为了让所有图看起来像同一款游戏，**每张图的提示词都以下面这段开头**：

> **【画风】** 东方幻想题材游戏美术，水墨淡彩结合工笔线描的风格。宣纸质感，墨色晕染，留白较多，低饱和度配色：以墨灰、米白、赭石、淡青为主，只有朱砂红和符纸的旧黄作为点缀色。线条细腻干净，光影柔和，带有一点雾气。人物比例写实偏修长，五官清秀含蓄，不要日系大眼动漫风，也不要厚涂写实油画风。画面里不要有任何文字、水印或边框。

**人物立绘额外加**：
> 全身立绘，人物站立，正面或微侧身，**透明背景**（如果不能透明，就用纯白色背景，并且人物边缘不要有阴影）。人物占画面高度的 90%，脚完整入画。

**场景图额外加**：
> 竖版手机游戏场景背景，画面中**没有人物**。画面下方三分之一构图比较简单，因为那里会叠加对话框。

## 三、人物设定（出立绘前先读）

| 人物 | 设定 |
|---|---|
| **顾长庚**（师父） | 外表约七十岁的修士，实际八十多岁。白发白须，长须及胸，头发用一根旧木簪束起。身形清瘦但背很直。穿洗得发白的灰青色宽袖道袍，袖口磨损。神情平静，目光很远，像在看山外的什么东西。 |
| **陆青棠**（师姐） | 二十岁左右的女修士，眉眼锋利，嘴角常带一点讥诮。头发挽成简单的发髻，插一根素木簪。穿青色窄袖修士服，**袖口沾着朱砂红的痕迹**，腰间挂着装符纸的布囊。站姿利落。 |
| **温小满** | 温家的女孩。三个年龄：8 岁（双丫髻，打补丁的碎花粗布衣，好奇大胆）、13 岁（抽条长高，头发编成一根辫子，手指上有墨迹）、28 岁（当家的年轻妇人，袖子挽起，干练，眼里有疲惫）。三个年龄的脸要能看出是同一个人。 |
| **温阿婆** | 七十多岁的老妇人，驼背，拄木拐杖，头上包深色头巾，满脸皱纹，眼神警惕又慈和。穿深褐色旧棉袄。 |
| **温晚** | 六十年前的女修士，永远停在二十岁。**半透明的魂魄**，周身有淡淡银白微光，衣角像雾一样消散。穿老式的留云山修士服（款式比青棠的更古旧）。长发披散，神情温柔安静。 |
| **阿禾** | 小满的女儿，8 岁，梳一个小发髻，穿干净的新布衣，和 8 岁的小满有几分像，但更文静。 |
| **饥祟**（异常） | 由六十年前饿死之人的怨气凝成。本体是一个巨大的、中空的人形阴影，身上缠着干枯的稻草和谷壳，伸出许多细长的手，每只手都捧着一个空碗。不血腥，要显得**悲哀**而不是恐怖。 |
| **饥影**（小怪） | 饥祟漏出来的碎片。半人高的瘦长黑影，四肢细长，腹部是空洞，眼睛是两点昏黄的光。 |

> 主角「你」不画立绘（玩家可以给主角起名）。插画里需要出现主角时，只画**背影**或**手部**，身穿留云山青色弟子服，看不出性别。
