# 《归山》正式制作方案 v1.1（已确认）

> 原型已经验证了故事和选择的吸引力。从现在开始，目标是一款**完整的单机修仙游戏**：有修炼、境界、功法、法宝、历练、宗门这些修仙玩法，同时保留原型里已经证明有效的东西——在意的人、有后果的选择、看得见的时间流逝。
>
> 参考作品只是方向（2D 国风画面、修仙人生、宗门与传承、功法构筑），玩法、人物、剧情、美术全部原创。

---

## 一、一句话

**修仙人生模拟 + 长篇叙事**：你从凡人开始，一年一年地修炼、历练、结识人、做选择。数值会变大，但每一次变强，都是为了回去守住某个人、某扇门。

---

## 二、要先解决的一个矛盾

你的原始大纲写着：**避免后期一直重复刷怪、采药、炼丹、突破，只是数字越来越大**。
而《一念逍遥》这类游戏的核心恰恰是「挂机修炼 → 资源 → 突破」的循环。

我的建议是**用它的框架，不用它的无限循环**：

| 借用 | 改造 |
|---|---|
| 境界、修为条、突破 | 每个大境界的突破都绑定一段剧情或心境考验，不是攒够数值就能过 |
| 功法、法宝、丹药 | 数量少而精，每一样都改变战斗或探索的方式，而不是单纯加属性 |
| 历练地图、采集、遇敌 | 地图上的事件大多是写好的，重复刷取的收益递减 |
| 时间流逝、寿元 | 闭关、历练都消耗游戏内的时间；寿元给人生一个终点，也给「传承」一个理由 |
| 宗门、同门、弟子 | 关系用事实记录（原型里的做法），而不是好感度数字 |

## 三、游戏结构

### 1. 主界面：洞府（参考修仙手游的主城界面）

```
┌───────────────────────────────┐
│ 练气七层 ▓▓▓▓▓▓░░ 修为 2340/3000 │  ← 境界与修为
│ 灵石 128   寿元 63/120   太初十二年·秋 │
├───────────────────────────────┤
│                               │
│        （主角所在场景插画）           │
│        （同门/弟子立绘站在旁边）       │
│                               │
│  [当前目标]  第二归：去槐荫村看看     │
├───────────────────────────────┤
│ 闭关  功法  行囊  炼丹  制符  历练  │  ← 功能入口
│ 宗门  人物  旧事录          菜单    │
└───────────────────────────────┘
```

### 2. 核心玩法

| 系统 | 内容 | 和故事的关系 |
|---|---|---|
| **闭关修炼** | 选择闭关时长（一月、一年、十年），修为增长，世界随之变化 | 闭关就是「时间跳转」，出关后人物会长大、变老、离开 |
| **境界突破** | 练气（九层）→ 筑基 → 金丹 → 元婴 → 化神；大境界需要心境事件 | 每个大境界对应一章剧情的高潮 |
| **功法** | 一部主修心法决定修行流派（符修、剑修、丹修、体修……），外加若干术法 | 主修流派不同，同一事件会有不同解法 |
| **术法挑战（战斗）** | 保留原型的回合制：敌人意图、暗处、护盾、心结；从功法里选 6–8 个术法带入战斗；普通小怪可「速战」自动结算 | 重要战斗都有战斗以外的目标（保护、仪式、心结） |
| **行囊与法宝** | 法宝带一个特殊效果（例如铜镜：可看见残魂）；丹药、符箓、材料 | 关键法宝来自剧情 |
| **炼丹 / 制符** | 配方 + 一个轻量小游戏（制符沿用原型的描笔） | 剧情里的「补符」就是制符系统 |
| **历练地图** | 区域地图上有村庄、山林、坊市、秘境等节点；移动消耗天数；节点里有固定事件和少量随机事件 | 槐荫村就是地图上的一个节点，可以随时回去看看 |
| **宗门** | 留云山：职位、贡献、同门、宗门任务；后期可以自立宗门、收徒 | 「自立与传承」一章的核心 |
| **人物** | 同门、凡人、对手、道侣（可选）、弟子；每个人有自己的事件链和年龄 | 原型里的小满、青棠、阿婆都在这里 |

### 3. 故事：六章（沿用原始大纲）

| 章 | 内容 | 境界 | 原型内容的位置 |
|---|---|---|---|
| 一 · 凡人入道 | 渡口少年，遇老道，上山 | 凡人 → 练气 | 新写 |
| 二 · 山门求学 | 学符、同门、第一次下山 | 练气 | **第一归**（槐荫村、麦饼、补笔） |
| 三 · 下山历练 | 坊市、秘境、其他宗门、太衡宗初现 | 练气 → 筑基 | **第二归**（三种解法） |
| 四 · 师门变故 | 太衡宗与六十年前的旧案 | 筑基 → 金丹 | **第三归**、师父的结局 |
| 五 · 自立与传承 | 自己守一座山门，收徒；阿禾这一代 | 金丹 → 元婴 | 新写 |
| 六 · 终局 | 与太衡宗的了断、主角自己的结局 | 元婴 → 化神 | 新写 |

目标时长：主线 15–20 小时，加上支线 20–30 小时（与原始大纲一致）。

## 四、画面与界面

- **画风**：国风 2D 动画风（等 A / B 两张青棠的对比结果定稿）。
- **界面**：统一的国风 UI 套件——卷轴面板、玉牌按钮、印章、符纸选项、云纹边框，全部用代码绘制，保证清晰、不糊、动画流畅。
- **动效**：场景切换、立绘入场、术法释放、突破、获得物品都要有专门的动效和音效。
- **流畅度标准**：所有点击 100 毫秒内有反馈；场景动画不掉帧；任何时候都不卡住。

| 敌人 | 20–30 张 | |

## 七、已确认的决定（2026-11-04）

| 问题 | 决定 | 落实方式 |
|---|---|---|
| 离线时间 | **修为继续增长** | 退出期间按真实时间累积「闭关所得」修为（上限 12 小时），回来时一次结算；**游戏内日历不随离线前进**，人物不会因为你没玩就老去——时间只随你的行动推进 |
| 战斗 | **手动回合制** | 保留原型的意图、暗处、护盾、心结；普通遭遇提供「速战」自动结算 |
| 主角 | **可以选择** | 创建角色时选性别、相貌（每种性别 3 种）、灵根；对白里依然称「你」，避免性别化代词 |
| M1 范围 | **同意** | 见下一节 |
| 补充 | **整体动态** | 立绘呼吸与随风摆动（WebGL 网格变形）、场景粒子与镜头推移、界面动效、战斗特效、修炼与突破特效 |

## 八、M1 详细范围

1. **创建角色**：姓名、性别、相貌、灵根（金木水火土；单灵根到五灵根，越纯修炼越快；可重掷两次）。
2. **洞府主界面**：动态场景背景 + 主角立绘；顶部境界、修为、灵石、寿元、日期；底部功能入口。
3. **时间与离线**：游戏内日历（年、月）；闭关、历练消耗时间；离线修为结算。
4. **修炼与境界**：凡人 → 练气一至九层；小境界攒满修为即可突破，练气圆满后的「筑基」作为 M2 的门槛。
5. **功法与术法**：主修心法（M1 提供 3 部：留云符经、青木长生诀、烈阳锻体功），决定修炼速度与术法加成；术法从已学会的里选 6 个带入战斗。
6. **行囊**：丹药、材料、符箓、法宝；可使用、可查看。
7. **新版战斗**：沿用原型规则，加入灵根五行克制、法宝被动、全套动画特效、速战。
8. **历练地图**：一张手绘区域地图（渡口、槐荫村、留云山、青石镇、雾隐林、断崖），节点之间移动消耗天数；每个节点有固定事件与少量随机事件。
9. **剧情**：第一章「凡人入道」（新写）+ 第二章「山门求学」（含原型的第一归）。
10. **动态**：上表全部。
